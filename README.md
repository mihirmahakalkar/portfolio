# Mihir Mahakalkar

Personal site. It is a static Next.js app published with GitHub Pages at [mihirmahakalkar.github.io/portfolio](https://mihirmahakalkar.github.io/portfolio/).

## Local

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## GitHub Pages

Pushes to `main` or `master` build the site and deploy it. The repository name must be `portfolio`, and GitHub Pages must use GitHub Actions as the source. The published site is served from `/portfolio`.
